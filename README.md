## 🚀 Featured Projects

### 🔒 [ZTA Guard — Zero Trust Security Scanner](https://github.com/AryanPawr/zta-guard)
Python CLI tool that audits applications against Zero Trust Architecture principles via static (Dockerfile) and dynamic (live endpoint) analysis. Outputs a weighted ZTA compliance score with executive-level reporting.  
`Python` `Zero Trust` `DevSecOps` `CLI` `OWASP`

### 🎣 [PhishGuard — Phishing Detection Platform](https://github.com/AryanPawr/Phishguard)
End-to-end phishing detection system combining a Manifest V3 browser extension, FastAPI backend, and ML pipeline (TF-IDF + Logistic Regression). Detects 90%+ of simulated phishing scenarios with JWT-secured telemetry.  
`Python` `FastAPI` `Machine Learning` `Browser Extension` `Cybersecurity`
